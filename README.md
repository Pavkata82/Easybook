# 🏨 Easybook

Easybook е уеб приложение за резервация на хотели, разработено с ASP.NET Core, Razor Pages и Entity Framework. Проектът предоставя възможност за сърфиране и резервиране на хотели според избрани дати, с роля-базирана автентикация и Stripe плащания.
